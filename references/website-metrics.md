# Website labels → contract evidence

**Historical methodology observations began September 25, 2026; current Reports composition requires a fresh source check.** Website text identifies the question and calculation rules; it is never a numerical input for balances, prices, valuation or settlement. The [shareholder app](https://app.netnet.capital/), [original inspected adapter](https://app.netnet.capital/assets/index-BssLYnjl.js) and [same-day replacement](https://app.netnet.capital/assets/index-hABaJsIB.js) establish dated terminology/interfaces, not timeless inclusion rules or deployed correctness. Discover current script URLs from official HTML and inspect them as text, without executing downloaded JavaScript. A current supported calculation can be reconstructed with RPC; changed or unavailable methodology leaves the current publisher total unverified. A separately observed headline may be compared with explicit time/unit qualifications, never used to force agreement.

## Answer contract

1. Use the supplied URL, section, label and series to resolve the metric. If “House” still could mean Predict or Book, ask which; do not load every product reference.
2. Select canonical identities and applicable read interfaces. Existing records and reviewed definitions are sufficient for ordinary questions: no mandatory website fetch or bundle download.
3. Read chain ID and a recent head, pin a block, then read all numerical inputs from the actual contracts. Retain contract/getter/arguments, raw units, scale, valuation basis, block/hash/time and coverage. Read-only price oracles are numerical inputs; website APIs are not.
4. Return the requested value when supported, its composition and material limitations. Reconcile Core independently. For combined assets, distinguish successful collection of a defined universe from proof of exhaustive asset/liability discovery; a partial subtotal must not masquerade as a total.
5. Preserve publisher definitions separately from economic adjustments. “Adjusted net assets” uses `rfv --scope net-assets`; it is not a replacement label for the website's gross/memo convention. Expose own-NET exposure, liabilities and unpriced assets separately. USDG is not independently established USD parity.

A contract can store an off-chain decision. In particular, a Safe-posted Predict print is an observed on-chain value, not an independently verified constituent valuation. If a calculation needs an off-chain mark or missing settlement transcript, name that dependency rather than silently filling it from the website. An actual display mismatch requires a separately dated website observation; RPC evidence alone cannot prove what a user saw.
